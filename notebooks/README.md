# notebooks/

Exploración libre: QAOA vs Markowitz, visualizaciones, comparativas.

**Diferencia con `theory/`:** los notebooks de `theory/` son el curso (permanentes,
con ruta de lectura y ejercicios). Los de aquí son cuaderno de análisis: se crean
para responder una pregunta concreta y se quedan como evidencia.

Convenciones:

- Un notebook = una pregunta (p. ej. `qaoa-vs-markowitz-n20.md`).
- La primera celda fija `seed` y documenta las versiones (`qiskit`, `numpy`).
- Si el resultado merece sobrevivir, se resume en `docs/learning-log.md`.
- Mismo formato MyST (`.md`) que `theory/`.
